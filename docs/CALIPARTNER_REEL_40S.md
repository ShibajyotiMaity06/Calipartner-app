## 4. EDITING SPECS (CapCut / Premiere Pro)

1. **Canvas:** 1080x1920, 24fps, H.264, 12 Mbps
2. **Cuts:** Every 1.2-1.5s (retention). Use J-cut on VO.
3. **Captions:** Burned-in, bold sans (Inter Black), white with black stroke, word-by-word pop (CapCut Auto Captions > Style: Bold).
4. **Transitions:** Camera push, match cut, morph - NO spin/3D.
5. **Color:** Light, clean, teal #14B8A6 accent, slate neutrals (never red/green competition per PRD 4).
6. **Safe zones:** Keep text inside 1080x1420 center (avoid Instagram UI overlap).

## 7. HOW TO GENERATE IN 10 MINUTES

1. Copy voiceover script → ElevenLabs → Generate + download MP3
2. Generate 8 clips in Veo 3 / Runway using prompts above (3-5s each)
3. Import clips + VO + trending music into CapCut (mobile or desktop)
4. Auto-captions > Bold style > Add on-screen texts from breakdown
5. Add screen recordings of app UI (Figma) between live clips (Scenes 3,4,5,6)
6. Export 1080x1920, 40s, 15MB max, post as Reel at 6-8pm IST
